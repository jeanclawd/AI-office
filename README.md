# AI‑Office MVP

This is a minimal, runnable MVP prototype of the AI‑Office concept derived from the demo video.

## What’s Included
- Pixel‑art styled 2D office map (canvas)
- Three agents with names and status labels
- Manager Office panel with tasks, command input, and output log
- Task assignment + simulated completion
- Arcade panel (placeholder for Pong/Tetris)

## Run
Just open `index.html` in your browser:

```bash
open index.html
```

No build step required.

## Notes
This MVP focuses on core interaction flow and UI structure. It does not include real agent intelligence or external integrations yet.
